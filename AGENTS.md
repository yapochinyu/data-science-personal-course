# data science personal course — правила для Codex

Личный практикум Python, NumPy, pandas и SQL. Работай по-русски.

- `tasks.md` — формулировки, `solutions.md` — разборы. Сохраняй номера и TODO. При проверке упражнения сверяй условие и решение.
- Для новых задач держи условие отдельно от ответа. Проверяй примеры в небольшом временном скрипте или SQL-базе с синтетическими данными.
- Luna подходит для повторов по образцу. Sol используй для проверки алгоритмических и SQL-пограничных случаев.
